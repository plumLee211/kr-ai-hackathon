# OOO's Adventure

### with Gemini Game Master

---

## 1. 프로젝트 개요

**Gemini 3 Seoul Hackathon** 출전작

- 시작은 **완전한 어둠** — 대화할수록 **Gemini 컬러가 세계를 물들이는** 턴제 RPG
- **Gemini Game Master**가 게임의 전면에 등장하는 가이드 캐릭터
- 설문 완료 시 **Gemini 컬러 폭발 + BGM 시작** → 감각적 보상
- **초반 개인화 캐릭터 + 아트에 올인** → 전투는 심플하게
- 같은 게임이지만 **매번 다른 경험** = 무한 리플레이

---

## 2. 초반 핵심 컨셉

### "대화할수록 세계가 물든다"

- 시작은 **완전한 어둠** — 흑백 도시, 무채색 타이틀
- Game Master와 대화할 때마다 **화면에 색상이 스며든다**
- 설문이 끝나는 순간 — **Gemini 컬러 폭발 + BGM 시작**
- "내가 대답할수록 세계가 살아난다"는 경험

---

```
[타이틀] OOO's adventure          ■ 완전 어둠 (무채색)
                │
   [Game Master 등장 + 이름 질문]  ■ 미세한 빛 (10%)
                │
   [MBTI 질문]                     ■ 보라빛 스며듦 (30%)
                │
   [좋아하는 동물 질문]            ■ 보라 그라데이션 + 달 (60%)
                │
   [멸망 아이템 질문]              ■ 마젠타 풀컬러 (90%)
                │
   [타이틀 전환] 김철수's adventure ■ Gemini 컬러 폭발 + BGM (100%)
```

## 4. 캐릭터 에셋 시스템

### 2종 구성: 도트 스프라이트 + 애니메이션 일러스트

- **Nano Banana 2 Flash**로 모든 캐릭터 이미지 생성
- output 프롬프트를 **사전 정제** → 도트/일러 각각 일관된 스타일 보장

| 종류           | 스타일                                     | 용도               |
| -------------- | ------------------------------------------ | ------------------ |
| 이동용 도트    | 48x48+ 모던 픽셀 (스타듀밸리/언더테일)     | 맵 이동, 파티 소개 |
| 컷신/전투 일러 | 애니메이션 일러스트 (페르소나/파판 택틱스) | 전투 UI, 컷신 연출 |

---

### 캐릭터별 에셋 매트릭스

| 대상     | 이동 도트 (48x48+) |  일러스트 (2~3장)  | 생성 기반            |
| -------- | :----------------: | :----------------: | -------------------- |
| 주인공   |         O          | O (기본/공격/피격) | 설문 "이름"          |
| 파티원 A |         O          | O (기본/공격/피격) | 설문 "MBTI"          |
| 파티원 B |         O          | O (기본/공격/피격) | 설문 "좋아하는 동물" |
| 파티원 C |         O          | O (기본/공격/피격) | 설문 "멸망 아이템"   |
| 보스     |         X          | O (기본/공격/피격) | 전체 설문 기반 생성  |

> **1 스테이지 기준**: 도트 4장 + 일러 10~15장 = **총 14~19장**

---

### 생성 파이프라인

```
[도트 스프라이트]
설문 데이터 → Gemini 3.1 (캐릭터 설정)
  → Nano Banana 2 Flash (48x48 모던 픽셀, 정면, 투명배경)
  → 정지 도트 이미지 출력

[애니메이션 일러스트]
설문 데이터 → Gemini 3.1 (캐릭터 설정 + 표정 지시)
  → Nano Banana 2 Flash (애니메이션 일러스트 스타일)
  → 기본 → 공격 → 피격 (순차 생성, 2~3장)
```

> 어떤 입력이 들어와도 **같은 세계관의 캐릭터**로 보이게 하는 것이 핵심

## 6. 스테이지 구성 — "바로 보스전" 전략

### 보스 등장 연출


> **핵심 트릭**: 파티 소개 화면을 보여주는 동안

## 7. 전투 시스템 — JRPG 클래식 턴제

- 검증된 JRPG 전투 방식 채택 (페르소나/파판 택틱스 스타일)
- 핵심은 전투가 아닌 **개인화 캐릭터 + 아트** → 전투는 심플하게
- 전투 UI에 **애니메이션 일러스트** 배치, 행동/피격 시 **표정 변화** 연출

```
┌─────────────────────────────────────┐
│         [보스 일러스트]              │
│         (표정 변화 연출)             │
│─────────────────────────────────────│
│ [파티원A 일러] [파티원B] [파티원C]   │
│  HP ████░░    HP ██░░   HP █████░   │
│  > 공격  > 스킬  > 아이템  > 방어   │
└─────────────────────────────────────┘
```

---

### 전투 턴 진행

```
[내 턴] 공격 / 스킬 / 아이템 / 방어
    ▼
[연출 + 데미지 계산] ← 일러스트 표정 전환
    ▼
[보스 턴] Gemini 3.1이 상황 기반 행동 결정
    ▼
[로깅] "턴 3: 김철수 - 얼음창, 바퀴벌레 마왕 - 촉각 휩쓸기"
    ▼
... 반복 → [보스 HP 0] → 클리어!
```

## 8. 보스 AI (Gemini 3.1)

- 매 턴마다 Gemini 3.1이 **상황을 분석**하여 보스 행동 결정

- 같은 보스라도 **매번 다른 전투 패턴** → 리플레이성 확보

---

| ----------- | ------------------------------------------ |
