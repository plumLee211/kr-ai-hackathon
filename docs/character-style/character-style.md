# 캐릭터 에셋 스타일 가이드

### OOO's Adventure — 이미지 컨셉 & 생성 파이프라인

---

## 1. 에셋 2종 구성

| 종류               | 스타일                         | 해상도                            | 용도               |
| ------------------ | ------------------------------ | --------------------------------- | ------------------ |
| **이동용 도트**    | 모던 픽셀 (언더테일)           | 스프라이트 시트 (4방향 x 4프레임) | 맵 이동, 파티 소개 |
| **컷신/전투 일러** | 애니메이션 일러스트 (페르소나) | 고해상도                          | 전투 UI, 컷신 연출 |

> 도트와 일러 **2종**으로 "이동 → 전투" 전환 시 시각적 임팩트를 극대화

## 2. 캐릭터별 에셋 매트릭스

| 대상                | 이동 도트 | 일러스트  | 생성 기반            |
| ------------------- | :-------: | :-------: | -------------------- |
| **주인공**          | O (1시트) | O (2~3장) | 설문 "이름"          |
| **파티원 A** (MBTI) | O (1시트) | O (2~3장) | 설문 "MBTI"          |
| **파티원 B** (동물) | O (1시트) | O (2~3장) | 설문 "좋아하는 동물" |
| **파티원 C** (음식) | O (1시트) | O (2~3장) | 설문 "좋아하는 음식" |
| **보스**            |     X     | O (2~3장) | 설문 "무서워하는 것" |

### 1 스테이지 기준 총 에셋

- 도트 스프라이트 시트: **4시트** (캐릭터당 4방향 x 4프레임 = 16프레임)
- 일러스트: **10~15장** (5캐릭터 x 2~3장)
- **합계: 스프라이트 시트 4장 + 일러 10~15장**

## 3. 이동용 도트 스프라이트 시트

### 스타일: 4방향 걷기 스프라이트 시트

- **레퍼런스**: 스타듀밸리, 언더테일, 오메가 스트라이커스
- **애니메이션**: **4방향 걷기 프레임 애니메이션** (방향당 4프레임)
- **방향**: **상(뒤) / 하(앞) / 좌 / 우** — 4방향
- **배경**: 단색 배경 권장 (후처리로 제거)
- **생성 도구**: Nano Banana v2

---

### 스프라이트 시트 구조

```
4행 x 4열 — 고정 순서:
┌────────┬────────┬────────┬────────┐
│ 상 F1  │ 상 F2  │ 상 F3  │ 상 F4  │  ← Row 0: 뒤(위) 걷기
├────────┼────────┼────────┼────────┤
│ 하 F1  │ 하 F2  │ 하 F3  │ 하 F4  │  ← Row 1: 앞(아래) 걷기
├────────┼────────┼────────┼────────┤
│ 좌 F1  │ 좌 F2  │ 좌 F3  │ 좌 F4  │  ← Row 2: 왼쪽 걷기
├────────┼────────┼────────┼────────┤
│ 우 F1  │ 우 F2  │ 우 F3  │ 우 F4  │  ← Row 3: 오른쪽 걷기
└────────┴────────┴────────┴────────┘
= 총 16프레임 / 1시트
순서: 상 → 하 → 좌 → 우 (프롬프트에서 이 순서를 명시)
```

---

### 도트 스프라이트 특징

```
특징:
- 둥근 머리 비율 (2~3등신)
- 또렷한 외곽선
- 제한된 색상 팔레트 (캐릭터당 4~6색)
- 설문 키워드가 시각적으로 바로 드러나야 함
  예) 불닭 → 붉은 계열 + 불꽃 이펙트
```

---

### 검증된 생성 프롬프트

Nano Banana v2 + 참조 이미지 기반 생성이 **고퀄리티 스프라이트 시트**를 출력함을 확인.

```js
// 강화된 프롬프트 (행 순서 고정)
const prompt = [
  { text: `다음 이미지는 "[캐릭터명]" 입니다.` },
  { inlineData: { mimeType: "image/jpeg", data: 참조이미지 } },
  {
    text: `
    - "[캐릭터명]"의 상하좌우 걷는 도트 스프라이트 이미지 생성
    - 4프레임 출력
    - 행 순서: 첫번째 행 상, 두번째 행 하, 세번째 행 좌, 네번째 행 우
    - 형광 초록 단색 배경 보장. 결과물을 바로 crop해서 사용할 수 있도록 해줘.
  `,
  },
];
```

---

### 프롬프트 핵심 포인트

> **핵심 포인트**:
>
> - 참조 이미지를 함께 넘기면 캐릭터 일관성 유지
> - **행 순서를 프롬프트에 명시** → 코드와 1:1 매칭
> - **형광 초록 배경** → Chroma-key 후처리로 제거
> - 머쉬룸맨 테스트에서 검증 완료

---

### 도트 스프라이트 시트 — 적용 대상

| 대상            | 시트 수량 | 비고                               |
| --------------- | :-------: | ---------------------------------- |
| 주인공          |   1시트   | 설문 "이름" 기반, 기본 용사 스타일 |
| 파티원 A (MBTI) |   1시트   | MBTI → 클래스/종족 매핑            |
| 파티원 B (동물) |   1시트   | 동물 → 의인화 or 동물 그대로       |
| 파티원 C (음식) |   1시트   | 음식 → 캐릭터화 (불닭 → 화염 닭)   |
| **보스**        |   **X**   | 이동 안 함 → 도트 불필요           |

> 도트는 **파티원만** 필요. 보스는 전투 일러로만 등장.

## 4. 컷신/전투용 애니메이션 일러스트

### 스타일: 애니메이션 일러스트

- **레퍼런스**: 페르소나 시리즈, 파이널판타지 택틱스, 파이어엠블렘
- **장수**: 캐릭터당 **2~3장** (표정/포즈 변화)
- **배경**: 투명 or 단색

---

### 일러스트 표정 세트

| 표정     | 사용 타이밍     | 설명                        |
| -------- | --------------- | --------------------------- |
| **기본** | 대기, 컷신 기본 | 평온한 정면 or 3/4 앵글     |
| **공격** | 스킬/공격 시    | 자신감 있는 표정, 액션 포즈 |
| **피격** | 데미지 받을 때  | 고통/놀람 표정              |

> 최소 2장(기본 + 공격), 여유 있으면 3장(+ 피격)

---

### 일러스트 — 적용 대상

| 대상            | 일러 수량 | 표정 세트          |
| --------------- | :-------: | ------------------ |
| 주인공          |   2~3장   | 기본 / 공격 / 피격 |
| 파티원 A (MBTI) |   2~3장   | 기본 / 공격 / 피격 |
| 파티원 B (동물) |   2~3장   | 기본 / 공격 / 피격 |
| 파티원 C (음식) |   2~3장   | 기본 / 공격 / 피격 |
| **보스**        |   2~3장   | 기본 / 공격 / 피격 |

> 보스는 **일러만** 존재. 전투 UI에서 가장 크게 표시.

## 6. 통합 생성 파이프라인

### 전체 흐름: 기본 일러 → 스프라이트 · 추가 표정 파생

```
[설문 데이터]
  │
  ▼
[Gemini 3] → 캐릭터 설정 텍스트 (이름, 외형, 클래스, 색상)
  │
  ▼
[Nano Banana v2] ── Step 2: 전투용 기본 일러스트 ← 텍스트만으로 생성
  │
  ├──→ Step 3: 기본 일러를 참조 → 스프라이트 시트 (4방향 x 4프레임, 초록 배경)
  │                                → Chroma-key 배경 제거 → 프레임 크롭
  │
  └──→ Step 4: 기본 일러를 참조 → 공격/피격 표정 일러스트 (1~2장 추가)
```

---

### 파이프라인 핵심 원칙

> **핵심**: 기본 일러스트가 캐릭터의 **"비주얼 기준점"** → 스프라이트, 추가 표정 모두 여기서 파생 → **일관성 극대화**

---

### Step 1 — 캐릭터 설정 생성 (Gemini 3)

```
설문 데이터 (이름, MBTI, 동물, 음식, 무서운 것)
  │
  ▼
Gemini 3: 게임 세계관에 맞는 캐릭터 설정으로 정제
  → 이름, 클래스/종족, 외형 키워드, 색상 팔레트
```

---

### Step 2 — 기본 일러스트 생성 (Nano Banana v2)

```
캐릭터 설정 텍스트
  │
  ▼
Nano Banana v2: 텍스트 프롬프트만으로 기본 전투 일러스트 생성
  "anime illustration style, [캐릭터 설명],
   neutral expression, upper body portrait, vibrant colors"
  │
  ▼
기본 표정 일러스트 1장 (= 비주얼 기준점)
```

> 이 일러스트가 이후 **모든 에셋의 참조 이미지**가 됨

---

### Step 3 — 스프라이트 시트 생성 (기본 일러 참조)

```
기본 일러스트 (Step 2 결과물)
  │
  ▼
Nano Banana v2: 참조 이미지 + 텍스트 프롬프트
  ┌─ 참조 이미지: Step 2의 기본 일러스트
  ├─ 프롬프트: "[캐릭터명]의 상하좌우 걷는 도트 스프라이트 이미지 생성"
  ├─ 행 순서 명시: "첫번째 행 상, 두번째 행 하, 세번째 행 좌, 네번째 행 우"
  ├─ "4프레임 출력"
  └─ "형광 초록 단색 배경 보장"
  │
  ▼
4방향 x 4프레임 걷기 스프라이트 시트 출력
```

---

### Step 4 — 공격/피격 표정 추가 생성 (기본 일러 참조)

```
기본 일러스트 (Step 2 결과물)
  │
  ▼
Nano Banana v2: 참조 이미지 + 표정 디렉션
  ┌─ 참조 이미지: Step 2의 기본 일러스트
  └─ 프롬프트: "same character, [표정: attacking/hurt],
     upper body portrait, vibrant colors"
  │
  ▼
공격 표정 1장 + 피격 표정 1장 (= 총 2~3장 세트 완성)
```

> **핵심**: 모든 프롬프트에 **스타일 키워드를 고정**하고, **Step 2 일러를 참조 이미지로 첨부**하여 캐릭터 일관성 보장

## 7. 스타일 일관성 전략

### 프롬프트 고정 키워드

| 종류 | 고정 키워드                                                   |
| ---- | ------------------------------------------------------------- |
| 도트 | `상하좌우 걷는 도트 스프라이트`, 참조 이미지 첨부, `4프레임`  |
| 일러 | `anime illustration`, `vibrant colors`, `upper body portrait` |

### 일관성 보장 방법

1. **프롬프트 템플릿 고정** — 변수는 캐릭터 설명만
2. **Gemini 3가 설명을 정제** — 설문 원본 → 게임 세계관에 맞는 설명으로 변환
3. **색상 팔레트 제한** — 캐릭터별 주요 색상 2~3개 지정

---

### 스타일 일관성 — 프롬프트 예시

```
설문: "불닭볶음면"
  → Gemini 3 정제: "화염을 다루는 붉은 닭 전사, 주황/빨강/노랑 팔레트"
  → 도트 프롬프트: "48x48 pixel art, fire chicken warrior, red orange palette..."
  → 일러 프롬프트: "anime illustration, fierce fire chicken warrior, red orange..."
```

## 9. 전체 에셋 파이프라인 (End-to-End)

### 처리 흐름

```
[설문 데이터]
  → Gemini 3 → 캐릭터 설정 텍스트
  → Nano Banana v2 → 기본 일러스트 (텍스트만으로 생성)
     │
     ├─→ 스프라이트 시트 (기본 일러 참조, 초록 배경)
     │     → Canvas 로드 → Chroma-key 배경 제거
     │     → 4x4 그리드 크롭 → 16 프레임
     │     → 방향별 배열 → rAF 걷기 애니메이션
     │
     └─→ 공격/피격 표정 일러 (기본 일러 참조)
           → 전투 UI 표정 전환에 사용
```

---

### 해결된 결정 사항

| 항목           | 결정                                                                  |
| -------------- | --------------------------------------------------------------------- |
| **배경 처리**  | 단색 초록 배경으로 생성 → HSL Chroma-key로 제거 (Hue 80~160, Sat>30%) |
| **크롭 방식**  | 균등 4x4 그리드 분할 (`frameW = width/4, frameH = height/4`)          |
| **렌더링**     | Canvas API (`drawImage` + `imageSmoothingEnabled = false`)            |
| **애니메이션** | 8 FPS (125ms/프레임), 방향당 4프레임 순환                             |
| **행 매핑**    | Row 0=상(뒤), 1=하(앞), 2=좌, 3=우 — 프롬프트에서 순서 명시           |

> **PoC 검증 파일**: `docs/custom-game/poc/sprite-poc.html`

---

### 남은 미결 사항

- AI 생성 시 행 순서(방향)가 매번 일관되는지 — 추가 테스트 필요
- 캐릭터마다 프레임 크기/배치가 균일한지 — 다양한 캐릭터로 테스트 필요
- 설문 기반 실시간 생성 시에도 동일한 품질이 나오는지
- Anti-aliasing 경계에 초록 잔여가 남을 경우 edge 처리 방안

### 도트 (모던 픽셀 스프라이트 시트) — 4방향 x 4프레임 걷기 애니메이션, 파티원만

### 일러 (애니메이션 스타일) — 전투/컷신용, 표정 2~3장, 전원

### 1 스테이지 = 스프라이트 시트 4장 + 일러 10~15장

> _"같은 세계관, 두 가지 얼굴 — 스프라이트로 걷고, 일러로 싸운다"_
