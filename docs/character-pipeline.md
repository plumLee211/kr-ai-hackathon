# 캐릭터 에셋 파이프라인

플레이어 설문 응답 1개 → 게임용 캐릭터 에셋 세트를 자동 생성하는 4단계 파이프라인.

## 파이프라인 흐름

```
설문 답변 (예: "강아지")
       │
       ▼
┌─────────────────────────────────────┐
│  Step 1. 설문 → 캐릭터 설정 JSON     │  gemini-3-flash (텍스트)
│  입력: surveyType + answer           │
│  출력: name, class, race,            │
│        appearance, colorPalette,     │
│        personality                   │
└──────────────┬──────────────────────┘
               │
               ▼
┌─────────────────────────────────────┐
│  Step 2. 캐릭터 설정 → 기본 일러스트   │  gemini-3.1-flash-image (이미지)
│  입력: appearance + colorPalette     │
│  출력: step2-base.png (1K, 1:1)     │
│  스타일: 페르소나 애니메이션           │
│  배경: 크로마키 초록 (#00FF00)        │
└──────────────┬──────────────────────┘
               │
       ┌───────┴───────┐
       ▼               ▼
┌──────────────┐ ┌──────────────────┐
│  Step 3.     │ │  Step 4.         │
│  스프라이트    │ │  표정 변형        │
│  시트 생성    │ │  (공격/피격)      │
│              │ │                  │
│  입력:       │ │  입력:           │
│  base.png    │ │  base.png        │
│  (참조)      │ │  (참조)          │
│              │ │                  │
│  출력:       │ │  출력:           │
│  sprite.png  │ │  attack.png      │
│  1K, 4x4    │ │  hurt.png        │
│  그리드      │ │  1K, 1:1        │
└──────────────┘ └──────────────────┘
```

## 사용되는 모델

| Step | 모델 | 용도 |
|------|------|------|
| 1 | `gemini-3-flash-preview` | 텍스트 → JSON 변환 |
| 2, 3, 4 | `gemini-3.1-flash-image-preview` | 이미지 생성 |

## Step 상세

### Step 1: 설문 → 캐릭터 설정 JSON

**입력**: 설문 유형 (`animal` / `mbti` / `item` / `fear`) + 답변 텍스트

**출력 JSON 스키마**:
```json
{
  "name": "한글 2~4글자",
  "class": "전사, 마법사, 궁수, 힐러, 도적, 소환사 등",
  "race": "인간, 수인, 엘프, 드워프, 정령, 요정 등",
  "appearance": "영어 3~4문장. 이미지 생성 프롬프트에 직접 사용됨",
  "colorPalette": ["#주색상", "#보조색상", "#강조색상"],
  "personality": "성격 한줄 요약 (한글)"
}
```

**설문 유형별 역할**:
- `animal` → 파티원 B (동물 특성 기반)
- `mbti` → 파티원 A (성격 유형 기반)
- `item` → 파티원 C (멸망 아이템 기반)
- `fear` → 보스 (공포 대상 → 위협적 존재)

**핵심 규칙**:
- `appearance`는 반드시 영어 (이미지 생성 AI에 직접 투입)
- `colorPalette`는 hex 코드 3개
- 단순 의인화가 아닌 판타지 세계관 해석

### Step 2: 캐릭터 설정 → 기본 일러스트

**입력**: Step 1의 `name`, `appearance`, `colorPalette` (텍스트만, 참조 이미지 없음)

**이미지 설정**: 1K, 1:1 비율

**스타일 규격**:
- 페르소나 시리즈 인스파이어 애니메이션
- 굵은 검정 아웃라인 (3~4px), 셀 셰이딩
- 전신 정면, 중립 서있는 포즈
- 크로마키 초록 배경 (#00FF00)

**프레이밍 고정**:
- 머리 꼭대기: 상단 10% 지점
- 발바닥: 하단 10% 지점
- 좌우 중앙, 캐릭터가 화면 높이의 80% 차지

### Step 3: 기본 일러 → 스프라이트 시트

**입력**: Step 2 기본 일러스트 (참조 이미지로 전달)

**이미지 설정**: 1K, 1:1 비율

**스프라이트 규격**:
- 모던 픽셀 아트 (스타듀밸리/언더테일 스타일)
- 2~3등신 비율, 둥근 머리
- 4행 4열 그리드 (총 16프레임)
- 행 순서: 상(뒤) → 하(앞) → 좌 → 우
- 제한된 팔레트 (4~6색), 또렷한 외곽선
- 크로마키 초록 배경

### Step 4: 기본 일러 → 공격/피격 표정

**입력**: Step 2 기본 일러스트 (참조 이미지로 전달) + 표정 유형

**이미지 설정**: 1K, 1:1 비율

**표정 유형**:
- `attack`: 자신감 넘치는 표정, 역동적 공격 포즈, 이펙트
- `hurt`: 고통스러운 표정, 방어 리코일 포즈, 데미지 흔적

**필수 조건**: 동일 캐릭터, 동일 스타일, 동일 프레이밍

## 출력 파일

```
output/test/
├── step1-setting.json       # 캐릭터 설정 (디버깅용)
├── step2-base.png           # 기본 일러스트
├── step3-sprite.png         # 스프라이트 시트 (4x4)
├── step4-attack.png         # 공격 표정
└── step4-hurt.png           # 피격 표정
```

## CLI 사용법

```bash
# 기본 (강아지 + animal)
pnpm pipeline-test

# 커스텀
pnpm pipeline-test "고양이" "animal"
pnpm pipeline-test "INFP" "mbti"
pnpm pipeline-test "기타" "item"
pnpm pipeline-test "거미" "fear"
```

## 후처리

생성된 PNG 이미지는 크로마키 초록 배경이므로 `extract-background.ts`로 투명 WebP 변환:

```bash
pnpm extract          # output/ 내 모든 PNG 일괄 처리
pnpm extract file.png # 단일 파일 처리
```

처리 과정:
1. Pass 1: 초록 배경 하드 컷 (G>150, 초록 지배 50+)
2. Pass 2: 그린 디스필 (초록 묻어남 중화)
3. 알파 채널 블러 (가장자리 부드럽게)
4. WebP 출력 (quality: 85)
